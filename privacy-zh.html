隐私说明

最后更新：2026 年 10 月 29 日

小灯屋不收集你的任何数据：没有统计、没有广告、不在后台上报。我们自己没有服务器，也看不到你在店里做了什么。

留在你电脑上的

称呼和设置；加密保存的 API Key（用系统自带的加密，只有这台电脑上的你能解开）；阿灯的小本子（做过的委托、你做的选择、卡住过的地方）；每次委托的运行记录；最近 7 天的运行日志；崩溃记录。

这些都在应用的数据文件夹里（Windows 上是 %APPDATA%\Lamplight Nook；商店版存在应用自己的存储区，卸载时 Windows 会一并删除）。小本子可以在设置里一键清空；用安装包装的，卸载后删掉这个文件夹，就什么都不剩。

店员做好的东西放在你选的委托文件夹里，归你所有。

会发给 Anthropic 的

店员靠你电脑上的 Claude Code 干活。你递的委托、补充的话、店员在委托文件夹里读到的文件内容、上网查资料的请求，会通过 Claude Code、用你自己的 API Key 发给 Anthropic 处理。这部分适用 Anthropic 的隐私政策和商业条款，费用记在你自己的 Anthropic 账户上。

存 API Key 时，小灯屋会向 Anthropic 发一次不收费的请求，确认这把 Key 能用。

除此之外，小灯屋不连任何服务器。店员查资料时会访问它们找到的网页。

诊断包

只有你在设置里点“导出诊断包”、并且自己发给我们时，它才会离开这台电脑。里面只有运行日志和电脑、设置的概况，不含 API Key，也不含委托内容。

联系我们

有问题可以通过 Microsoft Store 小灯屋页面上的支持方式联系我们。这份说明如有变动，会随新版本更新，并改上面的日期。
