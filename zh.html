小灯屋

一间温馨的像素小店，店员们用 Claude 帮你把电脑上的活儿做好。

即将上架 Microsoft Store9.99 美元买断，Windows 10/11。

在柜台递一张委托单，店员们就开工了。阿灯接单定计划，小橘跑腿查资料，青黛先定配色和布局，老石在成品出店前把关，店猫栗子负责监工。像素背后是 Anthropic 的 AI 代理 Claude Code，它在你电脑上的一个文件夹里干活，每一步都变成店里的日常。

委托真正的事

做个小网页、查资料写总结、改一份文档的复制件、给乱糟糟的文件夹出整理方案。

看着他们忙

跑腿、黑板和检查，代替一行行日志。

做主的是你

要选的地方阿灯会来问；有风险的一步等你点头。中途摇铃就能加要求。

小店记得你

做过的事、你的选择、踩过的坑，只存在你的电脑上。

小店有日子

天气和季节跟着日历走，节日会挂装饰；后院有狗麦芽和几只母鸡，街坊也会来串门。

你需要

  • 电脑上装好 Claude Code（免费，应用里会带你装）。
  • 你自己的 Anthropic API Key。店员用多少，你直接付给 Anthropic，小活儿一般不到 1 美元；每单花费都看得到，还能设上限。
  • 不用注册、不订阅、不收集使用数据。Anthropic 不提供 API 的地区用不了，包括中国大陆和香港。
